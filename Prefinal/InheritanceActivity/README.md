# 📖 Overview

This activity was created during our **Prefinal period** in **CS 211 - Object Oriented Programming**.  

The original project started as a simple **Student Information System** login interface using **Windows Forms Application (.NET Framework)** in C#.

Due to limited time and preparation for the **1-on-1 Oral Final Examination**, the project remained unfinished. However, instead of abandoning the activity completely, I decided to improve and restructure the project by applying actual **Inheritance concepts** discussed during our lecture.

The activity now demonstrates:
- Basic Windows Forms navigation
- Object-Oriented Programming structure
- Inheritance
- Encapsulation
- Role-based user classes
- Parent and Child Classes

---

# 🧬 Applied OOP Concepts

## ✅ Inheritance

The project now applies inheritance using:

```csharp
class Admin : User
class Teacher : User
```

Both child classes inherit common properties from the parent `User` class.

---

## ✅ Encapsulation

Properties are accessed using:
```csharp
get;
set;
```

Example:
```csharp
public string Email { get; set; }
```

---

## ✅ Polymorphism

The project also utilizes:
```csharp
virtual
override
```

to demonstrate method overriding.
