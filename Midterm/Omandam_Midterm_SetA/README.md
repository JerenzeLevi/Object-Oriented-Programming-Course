# 📖 Overview

BookApp is a simple Windows Forms application developed to demonstrate the principle of **Encapsulation** in Object-Oriented Programming.

The program allows users to enter information about a book and stores the data inside a custom `BookApp` class using private attributes and public getters/setters.

Upon clicking the **Save** button, the entered information is displayed through a MessageBox.

---

# 📝 Exam Task (Reconstructed)

Create a Windows Forms application that:

* Accepts book information from the user.
* Creates a custom class named `BookApp`.
* Encapsulates all attributes using private variables and getters/setters.
* Uses textboxes for user input.
* Displays the entered information when the user clicks the Save button.

# 🧠 OOP Concepts Applied

## 🔒 Encapsulation

The project demonstrates encapsulation by storing book information inside a dedicated class using controlled access methods.

Example structure:

```csharp
private string title;
private string author;
private string publisher;
private int yearPublished;
```

Access is provided through:

```csharp
public string Title { get; set; }
public string Author { get; set; }
public string Publisher { get; set; }
public int YearPublished { get; set; }
```

---

## 🧩 Object Instantiation
