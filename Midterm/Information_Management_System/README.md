# 📖 Overview

Information Management System is a simple Windows Forms application developed to demonstrate the use of **Classes**, **Objects**, and **Methods** in Object-Oriented Programming.

The application stores predefined personal information inside a custom class and displays the information through a MessageBox when the user interacts with the interface.

This activity serves as an introduction to organizing data and behavior inside a dedicated class.

---

# 📝 Activity Description

Create a custom class named:

```csharp
UserClass
```

The class contains personal information such as:

* User ID
* Name
* Age
* Address

A method named:

```csharp
displayInfo()
```

is responsible for displaying the stored information inside a MessageBox.

The form contains a button that calls this method when clicked.

# 🧠 OOP Concepts Applied

## 🧩 Class

A custom class named:

```csharp
UserClass
```

was created to store user information.

---

## 📦 Attributes

The class contains:

```csharp
userId
userName
userAge
userAddress
```

These represent the data associated with the user.

---

## ⚙️ Method

The class contains a method:

```csharp
displayInfo()
```

which displays the stored information using a MessageBox.

---

## 🚀 Object Instantiation

An object of `UserClass` is created in the form and used to access the `displayInfo()` method.

Example concept:

```csharp
UserClass user = new UserClass();
user.displayInfo();
```

# 📚 Learning Reflection

This activity introduced the fundamental concepts of Object-Oriented Programming by demonstrating how:

* Data can be stored inside classes
* Objects can be created from classes
* Methods can perform actions using stored data
* User interfaces can interact with class objects

It serves as a foundation for more advanced OOP topics such as encapsulation, inheritance, and polymorphism.
